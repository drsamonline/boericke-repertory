What it does

Three things, done properly

A repertory is only useful if you can move through it faster than the book. That is the whole brief.

01 — find

Search like a query

Six thousand rubrics, searched instantly with the operators you would expect — "exact phrase", -exclude, a or b — plus typo tolerance, and Gelsemium finds the source's own Gels. Prefer the book's structure? Browse walks it chapter by chapter.

02 — repertorise

Rank, then eliminate

Grade 2 counts two points, grade 1 one — or set your own weights, printed on the chart so it stays auditable. Mark rubrics must-have and fade every remedy that misses one. Tap any remedy to see every rubric that lists it.

03 — keep the case

Encrypted, if you want

Patient details, notes and prescription sit with the selection and the chart. Lock them with a passphrase and they are sealed with AES-256-GCM in the browser — the key is never stored. Print a one-page case sheet, export JSON or CSV, or copy a citation for any rubric that names the edition and the grades — and a source check that says whether the rubric matches the 1927 text exactly.

What it refuses to do

Nothing here phones home

A clinical tool that needs a connection is a clinical tool that stops working when you need it. These are limits, chosen on purpose.

✕
No accountThere is nothing to sign in to and no profile to maintain.
✕
No serverNo database, no API, no backend to be down. The app is a file.
✕
No network, everAfter the page loads it never opens a socket — from a USB stick, in a clinic with no signal, on a plane.
✕
No external assetsNo CDN, no web font, no analytics, no badge service — including on this page.
✕
No telemetryYour searches, your cases and your patients are not sent anywhere, because there is nowhere to send them.
✕
No silent changesThe version you downloaded is the version you run. Nothing updates behind your back.

The text

Where it comes from

The rubrics are Oscar E. Boericke's Repertory (1927), the companion volume to Boericke's Pocket Manual of Homoeopathic Materia Medica, 9th edition. The text is digitised from the public-domain edition at homeoint.org, presented by Médi-T.

The dataset was cleaned rather than copied: OCR variants of a remedy name are merged into one canonical name, duplicate rubrics are merged, and remedy-less category headings are kept for structure but never appear in search results — so every rubric you see carries at least one remedy.

The app

How it is built

One 821 kB HTML file: the stylesheet, the script and the entire dataset are inline. System fonts, CSS variables for the theme, and no build step — open it in a browser and it runs. The Windows executable and the Android APK are the same page in a shell, built from the same commit as the demo above.

The grade marks are the book's own: italic grade 2 counts two points, plain grade 1 counts one. Nothing is re-weighted or re-scored, so the chart can be checked by hand against the page.

Run it

Three ways in

  1. Open the live appNothing to install. play/ — works on phone, tablet or desktop.
  2. Keep the fileDownload index.html, double-click it. That is the entire installation, and it works with the Wi-Fi off.
  3. Self-hostFork the repo, enable GitHub Pages, and it is yours — one file, no configuration.

On a machine with no internet

Built for the clinic

Copy the file to a USB stick, a shared drive, or an old laptop in the consulting room. It opens the same way, with no licence check and no first-run download.

If you want it as an app icon on the home screen, use the browser's Install / Add to Home Screen — the page carries its own manifest and icon, so it launches full-screen and still never touches the network.

Releases carry the portable Windows build and the signed Android APK, each with its own icon.
